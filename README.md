# Учёт Fairy Baby

Сайт учёта склада подгузников Fairy Baby, магазинов, долгов и доходов.

- Сайт: https://lunat1k17.github.io/fairy-baby/
- Данные хранятся в Firebase Firestore (проект `fairy-baby`), вход по email и паролю.
- `firestore.rules` — правила доступа (только владелец). Их нужно вставить в Firebase → Firestore → Rules.
- В разделе «Журнал» есть перенос данных из файла и кнопка «Скачать копию данных».
